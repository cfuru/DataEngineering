1. Analyze the requirements from: $ARGUMENTS (this may be a PRD file path, a feature description, or a reference to an existing planning doc)
2. Generate parent tasks first and present them for approval
3. Wait for "Go" before generating sub-tasks
4. Save to docs/planning/tasks-[feature-name].md
